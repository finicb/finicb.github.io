将电脑本地代码项目上传到gitee

1，首先得有一个gitee仓库，自行创建，gitee官网

2，确保电脑已安装git，可以在cmd中 git –version 查看自己是否已经安装，未安装的去官网下载安装，GIit

1，在本地要上传到gitee的文件夹点击鼠标右键，选 git bush here，如图


2，进入到项目根目录，然后执行git命令


3，将项目的所有文件添加到仓库中，注意命令后面有一点


4，将add的文件commit到本地仓库。(双引号内容随便写)


5，将本地的仓库文件夹关联到gitee上，(https://gitee.com/XXX/XXX.git 是仓库的 https 地址)，地址复制到命令替换


6，将gitee上的仓库pull到本地文件夹

此时会弹出一个状态框，输入gitee账号密码即可

7，上传项目代码到gitee远程仓库

8，最后看一下有没有上传成功
