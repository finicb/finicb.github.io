N1搭建filebrowser个人云盘

发表于2026-08-17|更新于2026-08-17|斐讯N1
|总字数:799|阅读时长:3分钟|浏览量:

本教程N1所用的armbian版本 v26.08.0 for Aml.S905d running Armbian Linux 6.18.41-ophub，armbian版本众多也许安装方式有所差别，本教程仅供参考


查看armbian版本

查看基础发行版（Debian/Ubuntu）

用的 docker 方式安装 filebrowser，docker安装看这里

1，安装好docker后拉取官方 arm64 镜像，拉取太慢，可以用这里的N1镜像备份N1-filebrowser:v2-arm64

2，创建文件存储目录，配置文件和数据库目录

3，把宿主机目录的属主改成 1000:1000

4，启动容器

5，查看密码

或者这个查看

能看到 User ‘admin’ initialized with randomly generated password: xxxxxxxx 就成功了，密码注意大小写✅


6，登录

浏览器打开 http://N1的IP:8082

用户名：admin

密码：日志里那串随机字符（或你刚用命令设的新密码）

7，登录后立刻做两件事：

改密码：Settings → Profile → 修改密码，改密码要复杂一点的，系统默认强制要求最小 12 位

如果实在想用短密码，可以通过命令行修改（这会绕过前端的长度限制）

改语言：Settings → Language → 简体中文

如果想在其他 Armbian 版本的 N1 上重装 File Browser，就这套

这套命令在 Armbian 23.08、24.11、25.x 上完全通用​ ✅

如果不想用filebrowser了，要卸载执行下面命令

which filebrowser 没输出也印证了宿主机上没装独立二进制，直接删容器 + 清镜像

如果是用 docker run 手动跑的，上面就彻底清干净了

如果还想把数据也删掉（配置文件、用户数据库、你之前通过 FB 管理过的文件映射），看看当时挂载了哪些目录

如果没输出说明已经删干净了，容器和镜像都没了，docker inspect 报 No such object 是因为容器已经不在了，正常的

确认8082 端口是否占用

没输出就彻底清完了，干干净净
