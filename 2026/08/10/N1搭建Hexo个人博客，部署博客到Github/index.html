四，部署到远程仓库GitHub

1，注册github账号，github官网

2，新建仓库，仓库名最好和用户名一样，这里只做演示，和用户名一样，github 博客地址就是 https://用户名.github.io/ 短网址，而不是 https://用户名.github.io/仓库名.github.io/ 长网址

用户名格式需要注意，必须是 用户名.github.io

3，添加远程仓库地址

配置好公钥了，检查一下，输入 yes


SSH 认证已经成功

检查一下，输入 yes

8，打开仓库，在 Pages 设置页面打开 main 分支，然后点击 Save，最好看一下 _config.yml 里面是哪个分支

重要提示：GitHub Pages 设置的发布分支必须与 _config.yml 中 deploy 配置的 branch 保持一致。如果您的 _config.yml 中配置的是 branch: main，那么 GitHub Pages 也必须选择 main 分支作为发布源；如果配置的是 branch: master，则需选择 master 分支

稍等几分钟，就可以打开博客地址了，https://用户名.github.io/
