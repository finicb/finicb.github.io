环境：N1・Armbian（arm64）・外接硬盘 /mnt/usb・端口 5005・账号 admin

一、安装 rclone

二、启动 WebDAV 服务

看到 WebDav Server started on http://[::]:5005/ 即启动成功（Ctrl+C 停止测试）

三、防火墙放行 5005 端口

验证：ufw status verbose | grep 5005 显示 5005/tcp ALLOW IN Anywhere (v6)

四、验证访问

外网验证：手机关 WiFi 用流量访问 http://你的域名:5005/，弹出登录框输入账号密码即可

五、配置开机自启（systemd）

六、启用并启动服务

验证：systemctl status webdav 显示 active (running)

七、客户端连接

项目 值
内网地址 (WiFi) http://192.168.2.235:5005/
外网地址 (流量) http://你的域名:5005/
账号 admin
密码 安装时设置的密码
在家里，用内网地址 http://192.168.2.235:5005/
用流量 / 外地，用外网地址 http://你的域名:5005/

连接说明

  • 手机文件管理：ES 文件浏览器 / Solid Explorer → 添加 WebDAV
  • 手机看视频：nPlayer / VLC → 添加 WebDAV 源
  • 电脑：资源管理器 → 右键 “添加一个网络位置” → 输入地址

具体操作步骤

  • 电脑桌面 → 打开此电脑（文件资源管理器）
  • 空白处右键 → 添加一个网络位置 → 下一步
  • 选择 “选择自定义网络位置” → 下一步
  • 在 “Internet 或网络地址” 框里输入：

完成后，”此电脑” 里会出现一个网络位置（像磁盘一样），双击进去就是 N1 硬盘 /mnt/usb 的所有文件（相册、备份等），可以像本地文件夹一样复制、粘贴、删除
